# ADR-001: Adopcion de Scrum

## Estado
Aceptado

## Contexto
Proyecto con multiples actores y requisitos cambiantes.

## Decision
Scrum con sprints de 2 semanas.

## Consecuencias
- Reuniones diarias de coordinacion.
- Product Owner que priorice el backlog.
- Cada sprint entrega un incremento funcional.
